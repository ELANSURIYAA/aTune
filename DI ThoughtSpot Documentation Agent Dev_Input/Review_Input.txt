Reviewer Validation Checklist

Completeness Checks

- Instruction.txt is present and contains the full agent metadata (Agent Description, Expected Output, Agent Role, Agent Goal, Agent Backstory).
- All required input files (Input1.txt, Input2.txt, etc.) are present and readable in the DI ThoughtSpot Documentation Agent Dev_Input folder.
- All mandatory sections, fields, and analyses specified in the agent instructions are included in the output.
- All entities, tables, and sections from the input files are addressed in the output.
- All dependencies, integrations, and business rules from both instructions and input files are covered.
- All formatting and structural requirements from the instructions are followed.
- No required section or relevant input content is skipped or ignored.

Accuracy Checks

- Output aligns exactly with the provided agent instructions and expected output.
- Output correctly reflects the content of all provided input files.
- No hallucinated or unsupported content is introduced.
- All dependency and technical mappings are logically and technically correct.
- All gap identifications are justified by the input content.
- All business rule interpretations are correct and traceable to the instructions or input files.
- All terminology and formatting standards are used consistently and correctly.
- No false-positive gaps or false-negative omissions are present.
- All values, tables, and classifications accurately match the source content.
- No instruction is misinterpreted or partially implemented.

Efficiency Checks

- Duplicate analysis, explanations, and gap entries are avoided in the output.
- Output remains concise, well-structured, and free of unnecessary sections.
- Redundant dependency mappings, risks, recommendations, and validations are eliminated.
- Formatting is clean, optimized, and avoids excessive verbosity.
- Overlapping findings are consolidated and similar findings are grouped logically.
- Output is token-efficient while maintaining completeness and accuracy.
- Large sections are summarized efficiently where allowed by the instructions.
- Output structure improves readability and review efficiency.
