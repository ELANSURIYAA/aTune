Reviewer Validation Checklist

Completeness Checks

- Verify that all mandatory sections specified in the agent instructions are present in the output.
- Confirm that all required fields (overall mapping summary, configuration details, mappingResults, entityScores, AI insights) are included and populated in the output JSON.
- Ensure that all required analyses and justifications for mappings are covered, as per the instructions.
- Check that all formatting requirements for the output JSON structure are followed.
- Validate that all requested validations and mapping rules are present, even if no input file was provided.
- Confirm that all mandatory headers and sections from the expected output template are included.
- Ensure that gap/missing item handling requirements are addressed if mentioned in the instructions.

Accuracy Checks

- Confirm that the output strictly aligns with the provided agent instructions and expected output format.
- Ensure that no hallucinated content or unsupported assumptions are introduced in the output.
- Verify that all dependency mappings, technical mappings, and mapping rules are logically correct and justified as per the instructions.
- Check that all findings, recommendations, and AI insights are traceable to the instructions.
- Ensure that terminology and formatting standards are used consistently and correctly.
- Confirm that no contradictions exist across sections of the output.
- Validate that no false-positive gaps or false-negative omissions occur in the output.
- Ensure that no instruction is misinterpreted or partially implemented.

Efficiency Checks

- Confirm that duplicate analysis and redundant explanations are avoided in the output.
- Ensure that the output remains concise, well-structured, and free of unnecessary sections.
- Verify that repeated gap entries, dependency mappings, or recommendations are eliminated.
- Check that formatting is clean, optimized, and does not include excessive verbosity.
- Ensure that output structure improves readability and review efficiency.
- Confirm that large sections are summarized efficiently where allowed by the instructions.
- Validate that duplicate validations or checks are eliminated.
