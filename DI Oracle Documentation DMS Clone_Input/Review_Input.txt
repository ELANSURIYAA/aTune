Reviewer Validation Checklist

Completeness Checks

- Confirm that the agent output includes all sections explicitly required by the available instructions, if any.
- Verify that all available input files (if present) are referenced or addressed in the output.
- Ensure that any mandatory formatting or structural requirements from the instructions are followed, if specified.
- Check that no required content or section is omitted based on the available instructions and input files.

Accuracy Checks

- Validate that the output does not introduce unsupported assumptions or hallucinated content.
- Confirm that any data or content referenced in the output is traceable to the available instructions or input files.
- Ensure that terminology and structure, if specified, are used consistently and correctly.
- Check that no contradictions or misinterpretations of the available instructions occur.

Efficiency Checks

- Ensure that the output avoids unnecessary repetition or redundant sections.
- Confirm that the output is concise and does not include superfluous content.
- Verify that the output structure is optimized for readability and review efficiency.
- Check that no duplicate validations or checks are present in the output.
